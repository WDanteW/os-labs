## Вариант 10
Родительский процесс считывает из файла последовательность чисел и передает их дочернему процессу через первый пайп (`pipe1`). 
Дочерний процесс проверяет числа на простоту: составные возвращает через второй пайп (`pipe2`) в `stdout` родителя для вывода на экран, 
а отрицательные или простые вызывают немедленный досрочный выход (`_exit(0)`).

## Компиляция
Минимальные команды для компиляции проекта:
```bash
cc -o os_labs lab1/parent.c
cc -o child lab1/child.c
## Запуск
Запустите родительский процесс и введите путь к файлу с числами по вашему выбору:

Bash
./os_labs
При появлении запроса Enter filename: введите путь к файлу (например, lab1/numbers.txt).
