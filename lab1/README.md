# Лабораторная работа №1. Управление процессами и каналы (Вариант 10)

## Описание задачи
Родительский процесс запрашивает у пользователя имя файла, открывает его и создает дочерний процесс. Дочерний процесс считывает числа из файла (через перенаправление стандартного ввода) и проверяет их на простоту:
- **Составные числа** записываются в стандартный поток вывода, который через неименованный канал (`pipe1`) передается родительскому процессу для вывода на экран.
- **Отрицательные или простые числа** вызывают немедленный досрочный выход (`_exit(0)`).

## Компиляция
Минимальные команды для компиляции проекта:
cc -o os_labs parent.c
cc -o child child.c
Запуск
Запустите родительский процесс:

Bash
./os_labs
При появлении запроса Enter filename:  введите путь к файлу с числами (например, numbers.txt).
